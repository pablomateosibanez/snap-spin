# SnapSpin 📸💿

**Snap the cover, give it a spin.**

SnapSpin is a faster way to catalog your records on Discogs. The official app takes too many steps to add a single release to your collection. SnapSpin cuts that down to the essentials, and adds something it doesn't offer: point your camera at a cover and let the app do the searching for you.

## How it works

1. **Snap**: take a photo of the record's cover.
2. **Extract**: SnapSpin reads the key details, such as artist, title, label and catalog number.
3. **Match**: those details are used to search Discogs and suggest the matching releases.
4. **Add**: confirm the right pressing and it goes straight into your collection.

## Features

- Cover photo recognition to extract release information
- Streamlined flow to add releases with minimal steps
- Release search powered by the Discogs API
- Pick the exact pressing before adding it
- Manual search as a fallback when the cover isn't enough

## Requirements

- A Discogs account, authorized through the Discogs API
